## 2. Findings confirmed in code (by severity)

1. **Spec and model not separated.** The 64 laws are `S.pr_pN(...) == True{}`; each `pr_pN` is a Bool predicate
   in `v3/jetprot.bend` (lines ~1096-1140). `unit_eq` is `Nat.is_eq(unit_rank(a), unit_rank(b))` (line 328);
   `fin_eq` (331) composes it. **There is no** lemma `unit_eq(a,b)==True → a==b` (0 uses in LAWS/PROOF).
   An error in `pr_p9`/`unit_eq` would make the frame laws vacuous without Bend detecting it; the only safety net is C5
   (Python, same author).
2. **Self-referential mutant bank.** Reproduced: `HB_MAX=4` and `ACK_MAX=3` survive
   `recheck.catching_laws()` (7 s). Cause: `c6` (`v3/recheck.py:279`) restores only 13 functions and the laws are
   evaluated with the constants of the mutated model (`jetprot_ref.py:293` uses the module's `HB_MAX`/`ACK_MAX`).
   The README's "61/62" measures one class of defects, not the spec constants.
3. **F1 — JTT contaminates the table row.** `jtt_phase` sets `Termination` (`jetprot.bend:463-474`) and
   `concretize` indexes `table(i, p, t)` with that phase (881). After JTT in Heating2, a Slow reads the Termination row
   → PTN. No A-n declares it. [S2] describes this problem ("two views of time").
4. **F3 — CommFault ⇒ PTN unconditional** (`jetprot.bend:648`, `dms_on_commfault() = False`). [S1] says
   "*can* trigger" and conditions it on Level-1 masks; [S6] documents disruptions missed exactly there.
5. **F2 — local protection inhibits the whole unit for the pulse** (`local_fin`, 499-504; P8). R-9 speaks of one
   PINI. Declared in A-6 as a granularity limit, but in the opposite direction from the source: it must go in the
   summary, not in an annex.
6. **Reproducibility.** `v3/run.py` without `argparse` (`--help` launches the 6-min gate); Hypothesis with
   `database=None` and without `derandomize`/seed; `results.json`/`recheck.json` in `.gitignore`; `env/bend.sh`
   clones without `git checkout <commit>`; `env/check_env.sh:17` uses `bend --version` (removed in 2.0.17: it is
   `bend version`); no `requirements.txt`, `CITATION.cff`, CI or tag.
7. **Documentation debt.** Law names differ between docs and `.bend` (`stop_honoured` in traceability vs
   `d1_stop_honoured` in LAWS; 32/64 according to the auditor); `LAWS_JETPROT.bend:18` says "2 x 80 640 cells" and they are
   104 832 (comment from a version with 30 columns); `step_c_is_the_concrete_step` closes with `{==}`
   (definitional, not to be presented as a proven law).
8. **No liveness.** No response theorem over traces ("no heartbeat for `hb_max` ticks ⇒ PTN",
   "armed ⇒ Fired in ≤ `ack_max`"). It is the first thing a safety reviewer asks for. **→ §4.5: both theorems
   are proven** (`LAWS_JETPROT_LIVE.bend`), universal in `hb_max`/`ack_max` and in the configuration.

## 3. Nuances with respect to the auditors

- "TLA+ would do it in an afternoon": true for this size, but TLC does not give universality over `Nat` for the
  counters nor over the order as a parameter. The valid point is the absence of liveness, which TLC gives for free.
- "Single author": the real risk is that **all evidence layers share an origin** (Bend model, `pr_pN`,
  Python ref, mutants, Hypothesis). Way out: cross-check with a third-party tool (nuXmv, 1-2 laws) + external reading.
